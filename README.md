# Сервис сокращения ссылок

Консольное приложение сокращает HTTP и HTTPS адреса и открывает исходные страницы в браузере. Ссылки, UUID владельцев и счётчики хранятся локально в SQLite.

## Сборка и запуск

Нужны JDK 17 и Maven 3.6.3 или новее. При первой сборке Maven скачает зависимости, включая драйвер SQLite. Устанавливать SQLite отдельно не требуется.

```sh
mvn clean verify
java -jar target/link-shortener.jar
```

Из корня проекта приложение читает `config/application.properties`. Другой файл настроек можно передать первым аргументом после имени JAR. Путь к базе в настройках отсчитывается от каталога этого файла.

## Команды

| Команда                                | Действие                                            |
|----------------------------------------|-----------------------------------------------------|
| `create <URL> [лимит]`                 | Создать ссылку. При первом создании выводится UUID. |
| `open <код>` или `short/<код>`         | Открыть адрес в системном браузере.                 |
| `use <UUID>`                           | Продолжить работу с существующими ссылками.         |
| `new`                                  | Начать сессию для нового пользователя.              |
| `whoami`                               | Показать UUID текущего пользователя.                |
| `list`                                 | Показать действующие ссылки текущего пользователя.  |
| `edit <код> <URL или -> <лимит или ->` | Изменить адрес, лимит или оба параметра.            |
| `delete <код>`                         | Удалить свою ссылку.                                |
| `help`, `exit`                         | Показать справку или выйти.                         |

Например, введите `create https://example.org/guide 5`, затем вставьте полученную строку вида `short/Ab3x9Kq2` в консоль. Команды `open`, `edit` и `delete` принимают и код, и строку с префиксом. Сохраните выданный UUID для следующего запуска. Знание UUID даёт доступ к ссылкам владельца, поэтому делитесь только коротким кодом.

Изменение лимита сохраняет число уже сделанных переходов. Если увеличить лимит, заблокированная ссылка снова станет доступна до истечения срока жизни. Консоль сообщает об исчерпании лимита и об удалении просроченных ссылок. В среде без браузера она выводит исходный URL. Выдача этого URL также считается переходом.

## Архитектура и настройки

- `domain` содержит модель короткой ссылки.
- `application` реализует сценарии создания, перехода, редактирования, удаления и очистки. Сценарии используют интерфейс хранилища, источник кодов и часы.
- `infrastructure` реализует хранилище SQLite, чтение конфигурации и генерацию кодов. Первичный ключ и повтор генерации защищают от коллизий. Условное обновление счётчика в SQLite предотвращает превышение лимита при одновременных переходах.
- `cli` принимает команды, выводит сообщения и передаёт исходный адрес системному браузеру. `Main` связывает зависимости и запускает очистку.

По умолчанию срок жизни ссылки составляет 24 часа, лимит переходов — 10, максимальный лимит — 10 000. Эти значения и интервал очистки задаются в `config/application.properties`. Просроченные ссылки перестают открываться сразу и удаляются при запуске или фоновой очистке. Короткие коды работают через CLI с той же локальной базой.

## Тестирование

`mvn test` запускает модульные и интеграционные тесты JUnit. Они проверяют коллизии, права владельца, сохранение данных между запусками, параллельные переходы, границу срока действия, конфигурацию и обработку команд.

`mvn clean verify` дополнительно собирает исполняемый JAR и проверяет стиль через Spotless. GitHub Actions запускает ту же команду при push и pull request, затем проверяет запуск собранного JAR.
